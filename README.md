# 🛡️ Q-Shield: Quantum-Safe Key Distribution Simulator

Q-Shield is a web-based interactive application that simulates the **BB84 Quantum Key Distribution (QKD) Protocol**. It demonstrates how quantum physics principles protect cryptographic keys against eavesdropping threats posed by future quantum computing systems.

## ✨ Key Features
- **BB84 Protocol Simulation:** Interactive generation of qubits, basis selection, and key sifting between Alice and Bob.
- **Eavesdropper Detection (Eve):** Simulates intercept-resend attacks and dynamically calculates the Quantum Bit Error Rate (QBER).
- **Automated Threat Alert:** Automatically invalidates keys and flags intrusion if QBER exceeds the standard 11% threshold.
- **Interactive Metrics Dashboard:** Visual indicators for Sifted Key Length, Error Rates, and Final Security Status.

## 🛠️ Tech Stack
- **Language:** Python
- **Web Framework:** Streamlit
- **Data & Logic:** NumPy
